# What did you learn about how WordPress stores its files and data?

I learned that WordPress keeps its files in a structured system in different folders, like themes, plugins, and uploads, which helps in customizing how the website looks and works to keep everything organized and easy to manage. This also uses a database to store all the content of the website, like the posts, pages, and user information. Also, each of the tables holds specific types of data. 

# Which part was more complex: handling files or managing the database?

Managing the database was more difficult than handling the files. Because working with the database involved understanding how the tables are connected and making sure the data is correct. Also, this requires understanding how data is stored in tables, to back up, restore, or update data. 

# Why is version control useful for a WordPress project in an office setting?

Version control enhances reliability, security, and efficiency. It keeps track of all the changes made to files, so everyone can see what has been updated. This helps to collaborate effectively, prevent mistakes by maintaining backups, and have a clear record of the progress that is being made.
